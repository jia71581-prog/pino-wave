# Rank-30 Marmousi eight-source superposition

This figure uses the registered Marmousi slice with the largest input-only
velocity first-difference energy among all 30 candidates. Selection did not use
prediction or reference errors. The true velocity spans 1500--4450 m/s and
contains strong lateral discontinuities, dipping interfaces, and deep
high-velocity structures.

Eight independently sealed fixed-19-Hz source fields are added without
rescaling. Because the registered acoustic equation is linear in source
amplitude, this physical sum equals the field produced by the corresponding
eight simultaneous unit-amplitude sources. The same operation is applied to the
LWC-84 references and Phase4b predictions.

The summed all-401-frame relative L2 is 0.28828. Snapshot errors at 0.20, 0.36,
0.52, 0.68, 0.84, and 1.00 s are 0.1339, 0.2073, 0.2828, 0.3289, 0.3861, and
0.4644. This is qualitative complex-medium propagation evidence, not an accuracy
promotion, population estimate, or frequency-generalization result. The 4.51%
paper result belongs to a separate reused G3 Marmousi record and is not depicted
here.
