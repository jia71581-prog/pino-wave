# Evidence-gated acoustic research loop

## State snapshot

Capture repository path, active process tree, GPU utilization, disk, current accepted checkpoint/hash, run identity, terminal status, latest accepted metric, current attempt, and sealed-split status.

## Diagnose before proposing

Classify the limiting factor as data, numerical target, architecture, optimization, instance-adaptation basis, or protocol mismatch. Use aggregate plus family, early/middle/late, spectrum, phase/shift, and runtime evidence.

## Experiment ladder

1. Static contract or analytic capacity bound.
2. Unit test.
3. One-record or one-update train-only smoke.
4. Balanced train pilot.
5. Group-disjoint train confirmation.
6. One frozen complete validation.
7. One independent complete `test_id`, without further tuning.

Use oracle truth only to reject a direction or measure capacity on train data. Never turn an oracle multiplier into an online method.

## Serious-run record

Store JSON containing hypothesis, mechanism, primary metric, acceptance, failure signal, compute budget, data census, exclusions, exact digests, parent, command, rollback, and claim scope. Freeze it before launch.

## Long-run verification

Verify detached supervisor and children, log updates, GPU process agreement, run identity, schedule digest, checkpoint creation/retention, terminal semantics, and disk. Report accepted epochs separately from rejected retries.

## Stop conditions

Stop a route when its predeclared cheap gate fails, its oracle capacity is insufficient, its numerical contract is dishonest, or its runtime lower bound misses the target. Preserve artifacts and record the rejection before selecting a new conceptual variable.
