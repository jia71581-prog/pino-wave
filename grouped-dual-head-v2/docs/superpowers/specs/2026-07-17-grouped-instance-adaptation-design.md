# 起震对齐双快照的 Grouped U-FNO–MIONet 实例化微调设计

日期：2026-07-17  
项目：`/home/jiayh/Data/FNO-Acoustic-Wave-Simulation`

## 1. 目标与边界

在不改动正在运行的稀疏查询预训练作业的前提下，为一个新介质实例快速实例化
`GroupedSingleSourceUFNOMIONetOperator`。每个实例严格只有一个震源；输入为该实例
的速度场、`[x_s,z_s,f_0,t_0,A]` 震源参数，以及**从起震时刻对齐的前两帧完整波场**。
不使用接收器记录，也不读取或使用这两帧之后的参考波场作为适配损失。

输出是从起震后起始时刻到保存终点的完整 `[time,z,x]` 波场。研究重点是在极少的
实例更新内降低未来时刻误差，同时保持 LWC-84 物理一致性和可复现的速度–精度权衡。

实现位于新的 `grouped_ufno_mionet/instance_adaptation/` 与独立脚本、配置、工件目录中；
不得修改旧 FNO/DeepONet 的实例适配流程，也不得中断预训练。

## 2. 已知事实与设计约束

- 数据保存间隔为 `dt=0.0025 s`，而每个震源的 `t0` 在约 `0.05–0.1874 s`。因此全局
  帧 0、1 是起震前近零场，不能作为有效观测。
- 对记录 `i`，观测帧索引固定为
  `k0=ceil(t0_i/dt)` 与 `k1=k0+1`；若 `k1` 超出保存时间轴，记录无效。评估与物理
  采样仅使用 `k>k1` 的未来域。
- 当前预训练的可靠接口是 `prepare`/`query_encoded` 稀疏连续查询。现有
  `dense_head` 和 `source_encoder.map_proj` 未获得训练梯度，因此不能直接宣称其完整
  波场预测已校准。
- 既有 `src/fno_acoustic/instance_adaptation` 假设旧 `AcousticFNO3D` 状态字典及全场
  训练接口，不能加载 grouped checkpoint；只可借鉴其零初始化、接受门与无未来标签原则。

## 3. 方法：共享校准 + 每实例低秩适配

### 3.1 阶段 A：共享全场校准

从完成的 grouped 稀疏查询预训练 checkpoint 初始化，冻结 `medium_encoder`、
`source_encoder`、`trunk` 和 `query_head`。新增（或替换）受源条件控制的全场重建器，
将其训练为与 `query_encoded` 一致的低秩网格查询器，而不是依赖未训练的旧 dense head。

校准训练仅使用训练 split 的完整真值，且每条记录仍是一源一解。监督包括：

1. 随机全场块与完整时间帧的归一化 L1/L2；
2. 同一网格–时间位置的稀疏查询/全场输出一致性；
3. 空间–时间谱损失以约束相位和高频；
4. 起震前零场与顶部自由表面门；
5. 低成本、分块计算的 LWC-84 残差。

Validation 选择最佳校准 checkpoint，`test_id` 与 `ood_canonical` 不参与选择。

### 3.2 阶段 B：摊销双快照条件器

训练一个小型 `OnsetSnapshotConditioner`：输入起震对齐两帧、速度和震源；输出对全场
解码潜变量的零初始化残差。该残差只调制冻结共享模型的低秩输出，不修改介质编码器。
训练时采用 episode：把两个观测帧作为条件，未来波场只用于离线训练该条件器的监督；
部署时条件器不再需要未来真值。

这样 0 步实例化已有强基线，避免把少量梯度步用于从零拟合初始条件。

### 3.3 阶段 C：目标实例的快速微调

每个实例只允许更新以下零初始化、低秩参数：

- query 输出投影的 LoRA；
- 全场解码器的 LoRA/FiLM 缩放与偏置；
- 可选的时域潜变量残差。

默认冻结所有 U-FNO 谱层、介质编码器、源编码主干和坐标 trunk。适配参数预算小于总参数的
1%，优化预算 `B∈{0,1,5,10,20,50}`。只有当验证集显示复杂介质失败时，才开放最后一级
U-FNO 局部残差适配器，仍不解冻谱卷积。

每个更新的无标签目标为：

\[
L_{adapt}=L_{onset}+\lambda_{pde}L_{LWC84}^{future}
+\lambda_{energy}L_{energy}+\lambda_{anchor}L_{anchor}.
\]

- `L_onset`：预测在 `k0,k1` 与两帧观测一致；
- `L_LWC84^future`：只在未来预测场的随机时空块上计算，源项和速度已知；
- `L_energy`：限制能量漂移，防止物理残差的平凡近零解；
- `L_anchor`：限制相对校准模型的低秩漂移。

没有未来真值被送入适配器、损失、早停、学习率选择或接受门。适配中预测的观测帧通过硬投影
替换为真实两帧，因此输出严格满足可见初值。

## 4. 完整波场接口

`adapt_instance(...)` 返回冻结编码缓存、已拟合的低秩状态和审计元数据。
`predict_adapted_wavefield(time_s)` 分块返回 `[T,201,201]`，默认保存 `k0:` 之后的时间轴，
并可显式拼接硬投影的两帧。输出 HDF5 带有：原 checkpoint 摘要、实例 ID、`t0`、`k0/k1`、
可见帧掩码、适配步数、配置哈希及无未来标签声明。

## 5. 接受门与回滚

每个实例保留 0 步条件器输出作为基线。只有在以下条件同时成立时才接受梯度适配结果，否则
回滚基线：

1. 两帧观测相对误差不增加（硬投影后为零）；
2. LWC-84 残差不比基线恶化超过 2%；
3. 未来能量比位于 `[0.25,4.0]`；
4. 所有输出、损失和速度梯度有限；
5. 没有读取未来真值数据集键。

## 6. 实验协议

训练与调参仅使用 train/validation 且按 `group_id` 隔离。以 validation 选择模块、秩、损失
权重与更新预算；随后对 `test_id` 进行一次固定配置评估，并单列报告三个
`ood_canonical` 实例。每个实例至少三个随机种子。

报告：未来域全场 relative L2、每时间帧误差 P50/P95、频谱误差、LWC-84 残差、能量漂移、
0/1/5/10/20/50 步的 wall time、模型前向和全场重建吞吐。主要成功准则为：20 步内测试实例
中位 future relative L2 相对 0 步基线下降至少 20%，且至少 95% 实例通过物理接受门。若未满足，
如实报告速度–误差 Pareto，不作“高精度快速”结论。

## 7. 验证

- 起震帧索引、因果掩码、未来标签拒绝与硬观测投影的单元测试；
- checkpoint schema 与所有适配器默认恒等映射测试；
- 小型 CPU episode smoke：两帧损失可降、未来数据访问被记录为零；
- CUDA smoke：一次校准前向/反向和 20 步实例适配；
- 全场轴顺序、分块/非分块等价、速度输入梯度有限；
- 固定种子复现实验和接受门回滚测试。

## 8. 非目标

本工作不实现 FWI 反演器、不混合多源目标、不将同介质不同震源叠加、不把完整真值未来场用于
部署时微调，也不推送 GitHub。
