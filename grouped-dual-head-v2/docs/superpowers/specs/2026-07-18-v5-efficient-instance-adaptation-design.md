# V5 高效因果实例化微调与三类介质验证设计

日期：2026-07-18

项目：`/home/jiayh/Data/FNO-Acoustic-Wave-Simulation`

实现分支：`codex/grouped-dual-head-v2`

## 1. 目标

当 Saved-Time Phase Operator V5 的长程预训练无法继续显著降低完整验证误差时，
从**完整 480 条 validation 记录上误差最低**的 checkpoint 出发，设计一个高效、
无未来标签泄漏的实例化微调方法。每个实例仍严格对应一个速度模型和一个震源，
部署时仅可使用：

- 目标速度模型；
- 震源位置、主频、起震时间和幅值；
- 震源起振后的前两张完整 `201×201` 波场快照。

这里的两帧是目标实例在部署/实例微调阶段**唯一允许读取的真实波场快照**。任何更晚的
真实快照，即使仍可被称为“早期窗口”，也不得读取。模型必须输出原数据集全部保存时刻的
完整 `201×201` 波场。接收器波形只允许从预测
完整波场中事后抽取，用作诊断图和评价指标，不能进入模型输入、实例损失、早停或
候选接受判据。

本阶段不实现 FWI，不使用异常体介质，不推送 GitHub，也不中断当前预训练作业。

## 2. 启动条件和父 checkpoint

当前可比的完整验证基线是 epoch 5：

- aggregate relative L2：`0.5839557`；
- Uniform：`0.4520838`；
- Layered：`0.6410136`；
- Marmousi：`0.5717862`。

epoch 7 的 `0.547802` 来自抽样 panel，不能与完整 480 条验证直接比较。实例化研究的
默认启动点是 epoch 10 完整验证完成后；满足以下任一条件即视为预训练未能有效突破：

1. 完整验证 aggregate relative L2 仍高于 `0.10`；
2. 相对上一个完整验证最优值的改善不足 2%；
3. 任一介质族相对误差连续两个完整验证周期没有改善或恶化超过 3%。

父权重只能按完整验证 aggregate relative L2 选择。抽样 panel、测试集、实例未来真值和
接收器误差都不得参与父 checkpoint 选择。保存父 checkpoint 的 SHA-256、epoch、Git
commit、数据 manifest 和归一化摘要。

## 3. 现有结果不能作为实例化验证的原因

### 3.1 九记录 V3 结果是监督拟合

`artifacts/grouped_ufno_mionet_v3/nine_record_finetune/` 对九条固定 train 记录直接使用
未来完整波场和查询真值训练。其 aggregate dense relative L2 为约 5.99%，但这证明的是
九记录监督容量，不是仅凭两帧观测的部署时实例适配。该结果只作为模型容量上界，不能
计入本研究主结果。

### 3.2 旧适配器与 V5 不匹配

现有 `grouped_ufno_mionet/instance_adaptation/` 包装的是旧 grouped dense head，不包含
V5 的传播相位特征和深层谱解码器。旧 trainer 在硬投影观测帧之后主要优化 PDE 残差，
观测帧对适配参数缺少有效监督梯度；旧命令也没有完整执行接受/回滚策略。因此不能直接
把旧脚本换成 V5 checkpoint 后运行。

## 4. 候选方案

### 4.1 方案 A：纯潜变量适配

冻结全部预训练权重，每个实例只优化一个小型时空潜变量，并用 FiLM 调制 dense decoder。
该方案最快且不易破坏父模型，但两帧提供的信息有限，难以修复 Layered/Marmousi 的传播
相位和高频误差。它作为必要的低成本对照组。

### 4.2 方案 B：摊销双快照条件器 + 低秩物理适配（采用）

用训练 split 离线训练一个共享 `OnsetSnapshotConditioner`，将速度、震源和起震后两帧
编码为实例潜变量。部署时在此 0 步初始化之上，仅更新 V5 的小型 LoRA、FiLM 和实例潜变量，
并用短程 LWC-84 数值桥接和无标签物理约束校正。它兼顾初始化质量、适配速度和复杂介质
表达能力，是主方法。

### 4.3 方案 C：完整 dense decoder 微调

开放整个 dense decoder，用同样的两帧和物理损失优化。该方案参数多、速度慢，更容易通过
减小场能量获得虚假的 PDE 残差改善。它只作为容量和稳定性对照，不用于最终部署。

## 5. 主方法架构

### 5.1 冻结与可训练部分

默认冻结：

- medium encoder；
- source encoder 主干；
- 坐标和 travel-time 主干；
- V5 谱传播栈的预训练权重。

每实例允许更新：

- dense decoder 中 source/phase fusion 的 LoRA；
- 最后两级谱块局部投影的 LoRA；
- 输出投影 LoRA；
- 各级通道 FiLM 缩放与偏置；
- 一个实例时域潜变量。

LoRA 默认 rank 为 4，消融 rank 为 2/8。所有适配分支零初始化，初始输出必须与父模型在
数值容差内一致。每实例可训练参数目标不超过总参数的 1%，推荐控制在 0.3%–0.8%。

### 5.2 起震帧定义

保存时间间隔从数据集真实 `time_s` 读取，不硬编码。对震源起震时刻 `t0`：

```text
k0 = min{k | time_s[k] >= t0}
k1 = k0 + 1
```

观测是 `k0`、`k1` 两帧；若 `k1` 越界则拒绝该实例。所有主评价使用 `k > k1` 的未来域。
优化阶段不能先硬替换再计算观测损失；应在原始预测上计算两帧损失，使其产生有效梯度。
最终输出才执行硬投影，保证两个可见时刻严格一致。

### 5.3 摊销条件器

共享条件器在 train split 上按 episode 训练：

```text
速度多尺度特征 + 震源编码 + 两帧及其差分
                     ↓
             实例潜变量/FiLM 初值
                     ↓
       冻结 V5 + 零初始化低秩残差分支
```

训练 episode 可以用该训练记录的后续真值监督条件器，但 validation/test 的未来真值绝不
进入条件器训练。训练目标覆盖完整保存时刻，并按 Uniform → Layered → Marmousi 的课程顺序
稳定优化；每个 batch 保持三类平衡，独立介质是统计单位，同介质的不同震源不能跨 split。

### 5.4 短程 LWC-84 数值桥接

数据集保存网格为 `201×201, dx=dz=10 m`，保存间隔为 `0.0025 s`；生成器内部步长为
`0.000125 s`，即每张保存快照间隔 20 个内部步。VDS 和 shard 都没有保存 `401×401`
速度或 CPML 内存状态。因此禁止以 `0.0025 s` 直接做一个 LWC-84 更新，也禁止声称能够
精确恢复生成器的 401 网格状态。

从两张起震后观测估计时间导数，按与数据生成器一致的边界、网格、源项和 LWC-84 离散格式
在 201 保存网格上以 `0.000125 s` 子步推进，产生默认 4 个、消融 0/2/8 个后续保存时刻的
近似伪标签。桥接仅覆盖波前
未触碰未知边界状态的安全窗口；若 CFL、边界状态或离散缺陷门失败，则关闭伪标签项，回退
到条件器和物理残差适配。数值桥接产生的是由已知速度、震源和两帧计算的伪标签，不是读取
未来真实场，也不扩大允许读取的真实快照集合。桥接数组必须带 `synthetic=true` provenance，
且不能访问 HDF5 中 `k1` 之后的 pressure slice。

## 6. 实例优化

### 6.1 损失

实例目标为：

```text
L = L_obs
  + λ_bridge L_bridge
  + λ_pde L_LWC84
  + λ_phase L_spectral_phase
  + λ_energy L_energy
  + λ_anchor L_anchor
```

- `L_obs`：原始预测在 `k0/k1` 的幅值、空间梯度和两帧差分损失；
- `L_bridge`：短程数值桥接帧的稳健 Charbonnier/relative L2；
- `L_LWC84`：未来保存时刻三元组上的无量纲 LWC-84 离散残差；
- `L_spectral_phase`：低、中、高空间频带的复频谱幅相误差；
- `L_energy`：相对父预测和桥接窗口的能量包络约束，防止零场塌缩；
- `L_anchor`：低秩参数和实例潜变量相对零初始化的信赖域。

所有损失先做独立无量纲化，再组合。PDE 采样点由固定 seed 预生成并缓存，避免 GPU 等待，
同时保证后续 L-BFGS closure 完全确定。

### 6.2 优化器和预算

每实例默认：

1. 共享条件器进行 0 步初始化；
2. 12 步 fused AdamW，余弦下降，梯度裁剪 1.0；
3. 在固定桥接帧和固定 PDE 点上进行 3–5 次小参数 L-BFGS；
4. 保存 0/5/12/最终步的速度–误差 Pareto 数据。

若 5 步后观测损失、物理残差和能量门均未改善，则提前停止并回退。L-BFGS 只作用于确定性
小适配器，不沿用此前随机大模型 L-BFGS 的失败设置。

### 6.3 无真值接受门

候选只有同时满足下列条件才被接受：

1. 两张观测帧的原始预测损失相对 0 步初始化下降；
2. 无量纲 LWC-84 残差下降至少 5%，且不得恶化超过数值容差；
3. 未来能量相对父预测位于 `[0.5, 2.0]`；
4. 校正量 relative L2 不超过 50%，除非桥接伪标签误差同步显著下降；
5. 输出、梯度、优化器状态全部有限；
6. 数据访问审计确认只读取 `k0/k1` 两张目标实例真值。

任一条件失败，输出 0 步条件器结果；若条件器也失败，则回退到原始父模型。

## 7. 三类介质验证协议

### 7.1 试验单位和选择

从 validation split 固定选择 9 个独立介质：Uniform、Layered、Marmousi 各 3 个，每个介质
只选一条单震源记录。按震源横向位置、主频和起震时间分层，使每类包含低/中/高难度实例。
选择规则、seed 和 sample ID 在查看适配后未来误差之前封存。

同一实例上的四个方法做配对比较：

1. 父 V5；
2. 方案 A：纯潜变量；
3. 方案 B：条件器 + LoRA/FiLM + LWC-84；
4. 方案 C：完整 dense decoder 物理微调。

每个方法运行三个固定 seed。主结果以独立介质为统计单位，不能把时间帧或接收器数量当成
独立重复样本。

### 7.2 指标

在适配状态和接受决定封存后，独立 evaluator 才能读取 `k > k1` 的真实波场并计算：

- 全部原始保存时刻 future full-field relative L2；
- 每类均值、中位数、最差值和 bootstrap 置信区间；
- early/middle/late relative L2；
- 低/中/高频谱 relative L2 与 phase correlation；
- 每时间步误差 P50/P95；
- 虚拟接收器 normalized RMSE、relative L2 和到时/相位偏差；
- 每实例适配时间、完整 401 时刻推理时间、峰值显存和可训练参数量；
- 相对完整 LWC-84 数值求解的端到端加速比。

主要研究目标是三类介质各自 future full-field relative L2 均低于 10%。若未达到，必须报告
真实 Pareto 和失败介质，不得用九训练记录监督拟合结果替代。效率结论只有在端到端计时中
成立；目标为适配加完整预测相对 LWC-84 至少 10 倍加速。

## 8. 波场和接收器图

每类至少生成一张代表性波场图和一张波形图，同时保留九实例完整工件。

### 8.1 波场快照

在排除 `k0/k1` 后预注册三个时刻：起震后早期、全程中点和晚期高能帧。每个时刻按列展示：

```text
真实场 | 父 V5 | 适配后 | 父模型绝对误差 | 适配后绝对误差
```

真实场和两种预测共享以真值 99.5% 分位数确定的对称色标；误差图共享非负色标。图中标记震源、
时刻、介质类型和该帧 relative L2。

### 8.2 接收器波形

在看结果前固定 9 个近地表虚拟接收器，避开严格自由表面零值网格点，横向等间距覆盖模型。
所有波形由完整波场数组索引得到，不重新调用带接收器条件的模型。输出：

- 真实/父 V5/适配后三条曲线的代表接收器叠加；
- 9 道炮集的真实、父 V5、适配后和残差热图；
- 每道 normalized RMSE 与相位相关系数。

绘图使用 Matplotlib、色盲友好的 Okabe–Ito 配色，保存 PDF 和 300 dpi PNG；绘图脚本、输入
指标 JSON 和 sample manifest 一并保存以便复现。

## 9. 数据访问与可复现性

适配 dataset wrapper 只暴露速度、震源、时间轴及 `k0/k1` 两张早期真实快照。它不得提供
通用 pressure dataset 句柄、任意时间索引接口或 `k1` 之后的数据视图。未来真值文件句柄只能由独立
评估进程在适配状态封存后打开。设置测试：随机替换 validation 未来真值时，适配器状态哈希、
接受决定和运行日志必须完全不变。

每次实验保存：

- 父 checkpoint 与适配器 SHA-256；
- Git commit、配置及 manifest digest；
- 九实例 sample ID 和分层选择信息；
- 所有读取的目标波场帧索引；
- 优化轨迹、接受/回退原因和分阶段计时；
- 基线、各消融及主方法指标；
- 完整预测 HDF5、图表和绘图输入。

## 10. 验证顺序

1. 单元测试：起震索引、两帧访问守卫、LoRA 恒等初始化、观测梯度、硬投影、LWC-84 残差、
   固定采样、接受回退和未来标签防泄漏；
2. CPU 小网格 smoke；
3. 单个 Uniform CUDA smoke，确认损失有限、显存和耗时可控；
4. 每类一个实例的三记录 pilot；
5. pilot 无数据泄漏且主方法优于纯潜变量后，运行九实例正式验证；
6. 生成完整波场 HDF5、波场快照、接收器波形图和汇总报告。

任何阶段失败均保留工件并定位原因；修复验证通过后自动进入下一阶段，但不得绕过未来标签
访问守卫或把失败候选强制接受。

## 11. 非目标

- 不使用接收器记录训练或适配；
- 不预测或评价插值时刻，只处理原始保存时刻；
- 不在一个方程解中混合多个震源；
- 不实现 FWI；
- 不使用 anomaly 数据；
- 不以监督记忆训练实例冒充部署时微调；
- 不承诺在实验前必然达到 10%，只以封存协议下的结果作结论。
